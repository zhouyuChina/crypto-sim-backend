# 交易流水账户余额字段说明

## 📋 新增字段

交易流水接口返回的数据中新增了两个账户余额快照字段：

### 1. `entryAccountBalance` - 开仓时账户余额

**类型**: `number | null`

**说明**: 用户下单时的账户余额快照

**场景**:
- 记录用户开仓时刻的账户余额
- 用于核对交易前的账户状态
- 便于追溯用户的资金变化历史

**示例值**: `9850.50` (用户下单前账户有 9850.50 元)

---

### 2. `settledAccountBalance` - 结算后账户余额

**类型**: `number | null`

**说明**: 交易结算后的账户余额快照

**场景**:
- 记录交易结算后的账户余额
- 用于核对交易后的账户状态
- 配合 `entryAccountBalance` 可以精确计算本次交易对账户的影响

**示例值**: `9680.50` (结算后账户余额为 9680.50 元)

**重要**:
- 只有当交易状态为 `SETTLED` (已结算) 时,此字段才有值
- 未结算的交易此字段为 `null`

## 💡 前端使用示例

### TypeScript 接口定义

```typescript
interface TransactionLog {
  id: string;
  userId: string;
  userName: string | null;
  orderNumber: string;
  accountType: 'DEMO' | 'REAL';
  assetType: string;
  direction: 'CALL' | 'PUT';
  entryTime: string;
  expiryTime: string;
  duration: number;
  entryPrice: number;
  currentPrice: number | null;
  exitPrice: number | null;
  spread: number;
  investAmount: number;
  returnRate: number;
  actualReturn: number;

  // ✅ 新增字段
  entryAccountBalance: number | null;    // 开仓时账户余额
  settledAccountBalance: number | null;  // 结算后账户余额

  status: 'PENDING' | 'SETTLED' | 'CANCELED';
  createdAt: string;
  updatedAt: string;
  settledAt: string | null;
  isManaged: boolean;
  marketSessionId: string | null;
  marketSessionName: string | null;
}
```

### React 组件示例

```tsx
import React from 'react';

interface Props {
  transaction: TransactionLog;
}

export const TransactionItem: React.FC<Props> = ({ transaction }) => {
  // 计算本次交易的余额变化
  const balanceChange =
    transaction.settledAccountBalance !== null &&
    transaction.entryAccountBalance !== null
      ? transaction.settledAccountBalance - transaction.entryAccountBalance
      : null;

  return (
    <div className="transaction-item">
      <div className="transaction-header">
        <span className="order-number">{transaction.orderNumber}</span>
        <span className={`status ${transaction.status.toLowerCase()}`}>
          {transaction.status}
        </span>
      </div>

      <div className="transaction-details">
        <div className="detail-row">
          <span className="label">资产:</span>
          <span className="value">{transaction.assetType}</span>
        </div>

        <div className="detail-row">
          <span className="label">方向:</span>
          <span className="value">{transaction.direction === 'CALL' ? '看涨' : '看跌'}</span>
        </div>

        <div className="detail-row">
          <span className="label">投入金额:</span>
          <span className="value">${transaction.investAmount.toFixed(2)}</span>
        </div>

        <div className="detail-row">
          <span className="label">实际收益:</span>
          <span className={`value ${transaction.actualReturn >= 0 ? 'profit' : 'loss'}`}>
            ${transaction.actualReturn.toFixed(2)}
          </span>
        </div>

        {/* ✅ 显示账户余额快照 */}
        {transaction.entryAccountBalance !== null && (
          <div className="detail-row">
            <span className="label">开仓时余额:</span>
            <span className="value">${transaction.entryAccountBalance.toFixed(2)}</span>
          </div>
        )}

        {transaction.settledAccountBalance !== null && (
          <div className="detail-row">
            <span className="label">结算后余额:</span>
            <span className="value">${transaction.settledAccountBalance.toFixed(2)}</span>
          </div>
        )}

        {/* ✅ 显示余额变化 */}
        {balanceChange !== null && (
          <div className="detail-row highlight">
            <span className="label">余额变化:</span>
            <span className={`value ${balanceChange >= 0 ? 'profit' : 'loss'}`}>
              {balanceChange >= 0 ? '+' : ''}{balanceChange.toFixed(2)}
            </span>
          </div>
        )}
      </div>
    </div>
  );
};
```

      <div v-if="balanceChange !== null" class="detail-row highlight">
        <span class="label">余额变化:</span>
        <span :class="`value ${balanceChange >= 0 ? 'profit' : 'loss'}`">
          {{ balanceChange >= 0 ? '+' : '' }}{{ balanceChange.toFixed(2) }}
        </span>
      </div>
    </div>
  </div>
</template>

<script setup lang="ts">
import { computed } from 'vue';

interface Props {
  transaction: TransactionLog;
}

const props = defineProps<Props>();

// 计算余额变化
const balanceChange = computed(() => {
  if (
    props.transaction.settledAccountBalance !== null &&
    props.transaction.entryAccountBalance !== null
  ) {
    return props.transaction.settledAccountBalance - props.transaction.entryAccountBalance;
  }
  return null;
});
</script>

## 📊 常见使用场景

### 1. 显示账户余额历史

```typescript
// 在交易详情页展示用户的账户余额变化轨迹
const showBalanceHistory = (transaction: TransactionLog) => {
  console.log('开仓前余额:', transaction.entryAccountBalance);
  console.log('投入金额:', transaction.investAmount);
  console.log('实际收益:', transaction.actualReturn);
  console.log('结算后余额:', transaction.settledAccountBalance);

  // 验证余额计算
  const expectedBalance =
    transaction.entryAccountBalance + transaction.actualReturn;

  if (Math.abs(expectedBalance - transaction.settledAccountBalance) < 0.01) {
    console.log('✅ 余额计算正确');
  } else {
    console.warn('⚠️ 余额计算异常，请检查');
  }
};
```

### 2. 筛选异常交易

```typescript
// 筛选余额变化异常的交易
const findAbnormalTransactions = (transactions: TransactionLog[]) => {
  return transactions.filter(t => {
    if (
      t.status !== 'SETTLED' ||
      t.entryAccountBalance === null ||
      t.settledAccountBalance === null
    ) {
      return false;
    }

    // 预期余额变化 = 开仓余额 + 实际收益
    const expectedBalance = t.entryAccountBalance + t.actualReturn;
    const actualBalance = t.settledAccountBalance;

    // 允许 0.01 的误差（浮点数精度问题）
    return Math.abs(expectedBalance - actualBalance) > 0.01;
  });
};
```

### 3. 图表展示

```typescript
// 绘制账户余额变化曲线
import { Line } from 'react-chartjs-2';

const BalanceChart: React.FC<{ transactions: TransactionLog[] }> = ({ transactions }) => {
  // 按时间排序
  const sorted = [...transactions]
    .filter(t => t.settledAccountBalance !== null)
    .sort((a, b) => new Date(a.settledAt!).getTime() - new Date(b.settledAt!).getTime());

  const chartData = {
    labels: sorted.map(t => new Date(t.settledAt!).toLocaleString()),
    datasets: [
      {
        label: '账户余额',
        data: sorted.map(t => t.settledAccountBalance),
        borderColor: 'rgb(75, 192, 192)',
        backgroundColor: 'rgba(75, 192, 192, 0.2)',
      }
    ]
  };

  return <Line data={chartData} />;
};
```

## ⚠️ 注意事项

### 1. 字段可能为 `null`

- **`entryAccountBalance`**: 老数据可能没有此字段,值为 `null`
- **`settledAccountBalance`**: 未结算的交易 (`status !== 'SETTLED'`) 此字段为 `null`

**建议**: 在使用前先进行 `null` 检查

```typescript
if (transaction.entryAccountBalance !== null) {
  // 安全使用
  console.log('开仓余额:', transaction.entryAccountBalance);
}
```

### 2. 数值精度

余额字段使用数据库 `DECIMAL(18, 8)` 类型存储,前端接收为 `number` 类型。

建议使用 `.toFixed(2)` 或 `.toFixed(8)` 控制显示精度:

```typescript
// 显示两位小数
const displayBalance = transaction.entryAccountBalance?.toFixed(2);

// 显示八位小数（高精度）
const preciseBalance = transaction.entryAccountBalance?.toFixed(8);
```

### 3. 账户类型区分

交易流水分为两种账户类型:
- `DEMO` - 虚拟账户 (使用 `demoBalance`)
- `REAL` - 真实账户 (使用 `realBalance`)

显示时建议区分标识:

```tsx
<span className={`account-type ${transaction.accountType.toLowerCase()}`}>
  {transaction.accountType === 'DEMO' ? '模拟仓' : '真实仓'}
</span>
```

## 🔗 相关接口

以下接口的响应中都包含这两个字段:

- `GET /api/transaction-log` - 获取用户交易列表
- `GET /api/transaction-log/:orderNumber` - 获取单笔交易详情
- `GET /api/admin/transaction-log` - 管理员获取交易列表
- `POST /api/transaction-log` - 创建交易 (返回创建的交易)
- `PUT /api/transaction-log/:orderNumber/settle` - 结算交易 (返回结算后的交易)
